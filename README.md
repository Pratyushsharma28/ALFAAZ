## 🎭 About the Event

**ALFAAZ — UNFILTERED** is an inter-college cultural event celebrating creativity, individuality and raw talent.

A platform where students can express themselves, showcase their abilities and celebrate their passion without limits.

- **Event Date:** 18 December 2026
- **Venue:** Quad AI, Bengaluru
- **Organised by:** Social and Cultural Team, Quad AI
- **Theme:** UNFILTERED
- **Tagline:** No Rules. Just Raw Talent.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd alfaaz-unfiltered
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

### 6. Preview production build

```bash
npm run preview
```

The website is designed for deployment on **Vercel**.

1. Push the project to GitHub.
2. Connect GitHub to Vercel.
3. Import the project repository.
4. Configure the Vite build settings.
5. Deploy the website.
